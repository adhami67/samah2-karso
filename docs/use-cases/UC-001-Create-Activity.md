# UC-001 - ایجاد فعالیت

## هدف

مدیر مدرسه بتواند یک فعالیت جدید ایجاد کند.

## بازیگر

مدیر

## پیش‌نیاز

- ورود موفق
- Workspace فعال

## مراحل

1- مدیر وارد بخش فعالیت‌ها می‌شود.

2- روی "ایجاد فعالیت" کلیک می‌کند.

3- عنوان فعالیت را وارد می‌کند.

4- توضیح فعالیت را وارد می‌کند.

5- مهلت انجام را مشخص می‌کند.

6- گروه مقصد را انتخاب می‌کند.

7- ثبت را می‌زند.

## نتیجه

- Activity ایجاد می‌شود.
- Assignment برای گروه ایجاد می‌شود.
- Timeline ثبت می‌شود.
