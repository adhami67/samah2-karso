# Activity Workflow

## Statuses

- Draft
- Published
- Assigned
- In Progress
- Submitted
- Reviewed
- Completed
- Cancelled

## Allowed Transitions

Draft -> Published

Published -> Assigned

Assigned -> In Progress

In Progress -> Submitted

Submitted -> Reviewed

Reviewed -> Completed

Reviewed -> In Progress (Needs Revision)

Any -> Cancelled (Administrator only)
